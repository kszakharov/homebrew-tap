# 🍺 homebrew-tap

> Personal Homebrew tap for utilities, tools, and applications by [@kszakharov](https://github.com/kszakharov)

## Formulae

- **[rada](Formula/rada.rb)** — Minimal CLI for Apple’s on-device AI models

## Install

```shell
brew tap kszakharov/tap
brew install kszakharov/tap/<formula>
```

## Updating

```shell
brew update
brew upgrade kszakharov/tap/<formula>
```
